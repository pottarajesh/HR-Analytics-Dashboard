# HR Analytics Dashboard 📊

An interactive HR Analytics Dashboard built in Power BI to analyze 
employee attrition and workforce trends.

## Key Metrics Tracked
- Total Employees, Attrition Count & Rate
- Average Age, Salary, and Years at Company

## Insights Covered
- Attrition by Education, Age Group, Job Role
- Attrition by Salary Slab and Years at Company

## Tools Used
Power BI, DAX, Data Visualization, HR Analytics
